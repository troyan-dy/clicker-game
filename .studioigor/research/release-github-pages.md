## Что выяснено
| пункт | факт |
|---|---|
| размер и формат | статический сайт: `index.html` в корне ветки или в `/docs`; сайт не больше 1 ГБ, репозиторий — рекомендовано до 1 ГБ; у нас сборка 5,9 МБ |
| трафик | мягкий лимит 100 ГБ в месяц; при превышении сайт могут не отдавать или придёт письмо поддержки |
| сборки | мягкий лимит 10 сборок в час (не касается своего workflow в Actions); развёртывание обрывается через 10 минут |
| источник публикации | «Deploy from a branch» (любая ветка, папка `/` или `/docs`) или «GitHub Actions» (Settings → Pages → Build and deployment → Source) |
| тарифы | на GitHub Free — только публичные репозитории; из приватного — GitHub Pro, Team, Enterprise. Сайт публичен в интернете, даже если репозиторий приватный |
| адрес | `https://<логин>.github.io/<репозиторий>/`; Vite: `base` = `'/<репозиторий>/'` или относительный `'./'` (у нас `'./'` — работает из любой папки) |
| Jekyll | при публикации из ветки сайт прогоняется через Jekyll; файл `.nojekyll` в корне это отключает (нужен, чтобы ничего не выкинуло и не тратилось время) |
| Git LFS | Pages при публикации из ветки не подставляет файлы LFS — вместо картинок были бы указатели (не проверено по официальной странице; известное ограничение). В ветке со сборкой не должно быть `.gitattributes` с LFS |
| SDK, реклама, модерация | нет: это хостинг, не витрина |
| сохранения | localStorage на домене `<логин>.github.io` — общий для всех сайтов этого логина; ключ сохранения у игры свой (`SAVE_KEY`), обёрнут в try/catch |
| звук | браузер включает звук после первого нажатия — в игре так и сделано (`wake()`) |
| внешние запросы | в сборке их нет: шрифты, музыка и картинки лежат рядом |
| что делает человек | аккаунт GitHub уже есть (`gh auth status` — вход выполнен); решение «что становится публичным» |
| загрузка | `git push` ветки со сборкой + включить Pages (`gh api -X POST repos/<owner>/<repo>/pages`), либо workflow Actions; откат — вернуть прежний коммит ветки |
| Actions (если понадобится) | checkout → setup-node (lts, cache npm) → `npm ci` → `npm run build` → configure-pages v6 → upload-pages-artifact v5 (`./dist`) → deploy-pages v5; права `pages: write`, `id-token: write` |

## Что это меняет в плане
- репозиторий `clicker-game` приватный и пустой (ничего не отправлялось); тариф аккаунта по токену не виден → нужен выбор пользователя: отдельный публичный репозиторий только со сборкой, открыть исходники или публиковать из приватного (нужен Pro)
- публикуем готовую сборку веткой, без Actions: меньше движущихся частей, LFS не мешает
- автор коммитов в публичной ветке — адрес `noreply` GitHub, чтобы не светить почту
