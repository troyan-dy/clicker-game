# Stack — research (2026-11-13)

Игра: 2D бесконечный кликер, диорама во весь экран с отъезжающей камерой (6 масштабов), много
всплывающих чисел и частиц, магазин-панель, сохранение в браузере. Платформа: браузер на ПК
(свой сайт или инди-витрина). Стиль ещё не зафиксирован (доска style-r1) — выводы ниже помечены,
где они зависят от стиля.

## Findings
- Phaser 4: v4.0.0 «Caladan» вышел 2026-04-10 на новом WebGL-рендерере; последний найденный
  релиз — v4.2.1 «Giedi» (2026-07-09). Даёт сцены, камеру с зумом, твины, частицы, фильтры
  (свечение, размытие), свет. API отличается от Phaser 3 — модель может писать старый API,
  версию закрепить и сверяться с changelog v4.
- PixiJS 8: последний найденный релиз — v8.20.1 (конец августа 2026). Только рендер (WebGL/WebGPU);
  сцены, твины, ввод, звук собираются самим. Легче Phaser, но больше своего кода.
- Чистый DOM/SVG/CSS + TypeScript без движка: так устроен сам Cookie Clicker (DOM + canvas).
  Самая маленькая сборка, плоская векторная графика рисуется прямо в SVG; слабое место — тысячи
  движущихся объектов и эффекты свечения (UNVERIFIED: порог по числу объектов измерить в гиме).
- Godot 4.7 (июнь 2026): веб-экспорт по-прежнему только Compatibility/WebGL2, WebGPU нет; в 4.7
  добавлен wasm64. Размер веб-сборки в источниках не подтверждён (UNVERIFIED: по справочнику скилла
  ~5–9 МБ в сжатом виде). Имеет смысл, только если игра потом пойдёт нативно на ПК — этого в
  концепте нет.
- itch.io (если пользователь выберет его к фазе 10): ZIP с index.html в корне, имена файлов
  чувствительны к регистру; лимиты по вторичным источникам — 500 МБ распакованного, 200 МБ на файл,
  1000 файлов (UNVERIFIED, перепроверить в фазе 10 по itch.io/docs/creators/html5). Веб-игры по
  умолчанию принимают только пожертвования.
- Инструменты агента для веба: всё — код, кадры и ввод через Playwright, сборка секунды, аккаунты
  не нужны (оценка справочника: 5 из 5). Node и npm на машине уже есть.

## What this changes
- Unity, Unreal, Godot C# отпадают: платформа — только браузер, игра 2D и маленькая.
- Основные кандидаты: Phaser 4 (камера-зум, частицы и фильтры из коробки), PixiJS 8 + свой код,
  чистый DOM/SVG. Godot web — запасной вариант «на вырост в ПК».
- Зависит от стиля: «лендинг стартапа» и «мультяшная жвачка» делаются на любом из трёх;
  «неоновая серверная» требует WebGL со свечением (Phaser/Pixi, не DOM); «пластилиновая миниатюра»
  требует пререндера спрайтов в Blender и атласов (Phaser/Pixi) — Blender ставить в фазе 4.
- Магазин, лента новостей и числа в любом варианте проще делать HTML-слоем поверх канваса:
  текст чёткий, вёрстка дешёвая.
- Версии библиотек перепроверить в фазе 4 командой `npm view <пакет> version` перед установкой.
