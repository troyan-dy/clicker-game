# Assets — research (2026-11-13)

Игра: 2D-кликер в браузере, стиль «Жвачка и пиксели Клода» (гладкий вектор с контуром + квадратные
пиксели Клода), Phaser 4.2.1, интерфейс — HTML-слой. Генератор картинок — Codex (решение пользователя).

## Findings
- Вектор в Phaser 4: `this.load.svg(key, url, { width, height })` растеризует SVG в текстуру нужного
  размера (node_modules/phaser/skills/loading-assets); `Graphics` умеет скруглённые прямоугольники,
  дуги, пути. Значит, персонажи и предметы — SVG-файлы, простые формы и эффекты — `Graphics`.
- Шрифты: `@fontsource/rubik` 5.3.0 и `@fontsource/jetbrains-mono` 5.3.0, лицензия OFL-1.1, ставятся
  через npm и собираются Vite; у обоих есть подмножество cyrillic (проверить глазами в look-dev).
  Есть и вариативный `@fontsource-variable/rubik` 5.3.0 — один файл на все начертания.
- Звуки: `zzfx` 1.4.0 (MIT) — звук как строка параметров в коде, без файлов; `jsfxr` 1.4.1 — то же
  с пресетами (монета, взрыв, выбор). Для кликера с десятками срабатываний в секунду это удобнее
  файлов: высоту и громкость можно менять на лету.
- Звук в Phaser 4: WebAudio по умолчанию, разблокировка звука первым вводом встроена
  (skills/audio-and-sound); музыка — `load.audio` с ogg/mp3.
- Готовые наборы (CC0), если понадобятся: Kenney UI Pack и Interface Sounds — прямые zip со страницы
  kenney.nl/assets/<slug>. Стиль Kenney UI — плоский без толстого контура, с нашей арт-библией
  совпадает только частично (UNVERIFIED глазами — не скачивал).
- Музыка: CC0/CC-BY с OpenGameArt и incompetech (CC BY 4.0, нужна строка в титрах); чиптюн можно
  писать кодом (ZzFXM); генерация — платные сервисы, решение пользователя.
- Генераторы 3D (Tripo, Meshy) и Blender игре не нужны: 3D в ней нет, пластилин отвергнут на доске.

- Генерация картинок: Codex CLI 0.164.0 установлен и залогинен (ChatGPT); встроенный image_gen
  вызывается через `codex exec`, промпт подаётся в stdin, картинка копируется в рабочую папку. Готовая
  обвязка есть на машине: `~/.claude/skills/ref2game/scripts/gen.py` (провайдер codex, прозрачность через
  родной альфа-канал или хромакей; `gen.py check` показывает ready).

## What this changes
- Персонажи, предметы и фоны — генерация через Codex по арт-библии, с общим ключевым кадром как
  референсом стиля; `Graphics` и пул частиц — для эффектов и Клода; HTML/CSS — для денег, магазина,
  тикетов, новостей. Текст в картинках не генерируем.
- В реестр лицензий попадают шрифты (OFL), zzfx (MIT), музыка (CC0/CC-BY) и строка «generated (Codex)».
- Музыку подбираю сам из CC0/CC-BY и показываю на выбор (решение пользователя).
- Клода рисуем своим персонажем (оранжевый скруглённый квадрат с глазами-пикселями), логотип
  Anthropic не используем.
