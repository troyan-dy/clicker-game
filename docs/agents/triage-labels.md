# Метки для разбора задач

Имя каждой метки в GitHub совпадает с именем роли в навыках.

- `needs-triage` — задачу предстоит разобрать.
- `needs-info` — ждём уточнений от автора.
- `ready-for-agent` — задача описана достаточно подробно для самостоятельной работы агента.
- `ready-for-human` — реализация требует участия человека.
- `wontfix` — принято решение закрыть задачу без реализации.
